# 📊 Ecommerce Performance Dashboard (Looker Studio)

A 6-page Looker Studio dashboard that brings sales, advertising, email, traffic, profitability and inventory data into one live report for an ecommerce brand.

**Built by [Info Logic Solution](http://www.infologicsolution.com)**

## 🎯 Problem

Ecommerce teams often work across Shopify, GA4, Meta Ads and Klaviyo, and still can't easily answer: *"What is actually making us money?"*

## ✅ Solution

One dashboard that combines all sources, updates automatically and shows the metrics that drive decisions.

## 📑 Dashboard Pages

| Page | What it shows |
|------|---------------|
| **Sales Overview** | Revenue, orders, AOV, session duration, bounce rate, ecommerce funnel, top pages |
| **Ad & Email Performance** | Meta Ads (ROAS, CTR, CPA, impressions), Klaviyo (open rate, CTR, sales), revenue by source |
| **Email Marketing** | Campaign, flow and subject-line performance, orders by product |
| **Traffic Insights** | Traffic sources, session duration, bounce rate and conversions by channel |
| **Profitability** | Profit margin by product, ad spend vs. revenue, product performance |
| **Inventory Management** | Inventory value, sell-through rate, revenue and gross profit by product |

## 🔌 Data Sources

- Google Analytics 4
- Shopify
- Meta Ads (Facebook)
- Klaviyo
- Google Sheets (cost and inventory data)

## 🛠 Tools

Looker Studio · GA4 · Google Tag Manager · Shopify · Klaviyo · Meta Ads · Data Studio


## 💡 Key Insights Enabled

- Which products get views but few add-to-carts
- Which channels convert vs. only drive traffic
- Which email flows and subject lines perform best
- Whether ad spend is driving profit
